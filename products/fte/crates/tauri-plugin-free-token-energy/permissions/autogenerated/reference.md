## Default Permission

Read gateway state and use configured generation routes. Loopback listener control requires separate permissions.

#### This default permission set includes the following:

- `allow-gateway-status`
- `allow-gateway-models`
- `allow-gateway-generate`
- `allow-gateway-stream`
- `allow-gateway-cancel`
- `allow-loopback-status`
