# Architecture records

The [current decision index](../CURRENT-DECISIONS.md) is the entry point for new
work. It records which decisions remain applicable and which were superseded.

The dated ADR bodies and `SHA256SUMS.json` preserve the original W1 decision
packet. Its pre-repository instructions, migration choreography, proposed
research architecture, and acceptance criteria describe that historical phase.
They are not instructions to recreate retired systems or claims that current
code has passed those criteria. ADR-015 records the later macOS release direction.

Update the current index when architecture changes. Keep historical decisions
and their evidence interpretable without adding a second runtime claims system.
